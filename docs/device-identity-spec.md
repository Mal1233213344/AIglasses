# 设备身份与型号规则规范

## 1. 概述

本规范定义了儿童 AI 英语眼镜的唯一标识 (ID)、MAC 地址、序列号 (SN) 及其型号编码规则。

## 2. 设备唯一标识 (DeviceID)

设备唯一标识用于云端识别、绑定及指令下发。

- **格式**: `UUID v4`
- **生成时机**: 硬件首次联网激活时由后端分配，或硬件出厂预置。
- **持久化**: 写入硬件 Flash 分区，不可被用户重置。

## 3. MAC 地址与蓝牙广播

- **MAC 地址**: 采用 IEEE 标准 48 位地址。
- **主标识**: 云端以 `bluetooth_mac` 作为物理层主标识。
- **广播名规则**: `AI-Glasses-XXXX` (其中 XXXX 为 MAC 地址最后 4 位，大写)。

## 4. 序列号 (SN) 规则

用于售后、库存管理及高级身份验证。

- **长度**: 16 位大写字母/数字。
- **编码格式**: `[型号(2)][生产年份(2)][生产周(2)][流水号(10)]`
- **示例**: `ST26120000000001` (标准版, 26年第12周生产)

## 5. 型号编码 (ModelCode)

| 型号编码 | 产品名称 | 硬件配置 |
| :--- | :--- | :--- |
| **STD** | 标准版 | 无摄像头, 无对讲, 16GB 存储 |
| **PRO** | 专业版 | 1080P 摄像头, 单向对讲, 32GB 存储 |
| **MAX** | 至尊版 | 2K 摄像头, 双向对讲, 64GB 存储, 高性能处理器 |

## 6. 固件版本号格式

- **格式**: `vX.Y.Z-build`
- **示例**: `v1.2.5-20260330`
- **比较逻辑**: 语义化版本号 (SemVer) 比较。

## 7. 绑定状态规则

- **UNBOUND**: 出厂默认状态，持续广播。
- **BOUND**: 已绑定，仅允许已授权设备连接。
- **RESET**: 恢复出厂设置，清除绑定信息并重置为 UNBOUND。
